# Swapper and Checker

An Android application that demonstrates text manipulation, basic conditional logic, and activity navigation based on event triggers.

---

## 📋 Overview

This project showcases event-driven programming in Android. The application consists of two text fields and two action buttons: one button dynamically swaps the text content between the fields, while the other compares the contents and navigates to a new activity displaying whether the values are `SAME` or `NOT THE SAME`.

---

## 🎯 Objectives

* Program event listeners for button click interactions in Java.
* Dynamically fetch, swap, and manipulate text strings from `EditText` fields.
* Implement conditional comparison logic to determine string equality.
* Use Explicit Intents to navigate to a result screen and pass status messages.

---

## 🛠️ Tech Stack & Requirements

* **IDE:** Android Studio 3.3 or higher
* **Language:** Java & XML
* **JDK:** Java Development Kit (JDK) 8
* **Target Platform:** Android

---

## 📝 Key Features

1. **Swap Operation:** Clicking the **SWAP** button exchanges the string values present in the two text inputs.
2. **Check Operation:** Clicking the **CHECK** button evaluates if the strings match.
3. **Result Screen (`MyMessage`):** Launches a secondary activity displaying the comparison result (`SAME` or `NOT THE SAME`).

---

## 💡 Conclusion

This activity strengthens core concepts in event handling and basic input validation in Android development. It illustrates how UI inputs can be captured, manipulated logically in code, and passed dynamically across activities to communicate feedback to the user.
